# 24个月英语学习系统

## 电脑使用
双击 `index.html`（建议用 Edge 或 Chrome，朗读评分需要联网和麦克风权限）。
进度保存在浏览器里，请固定使用同一个浏览器。

## iPhone 使用（免费）
方案A（推荐）：把整个文件夹上传到 GitHub Pages 或 Netlify Drop（都免费，不需绑卡），
用 iPhone Safari 打开网址 → 分享 → 添加到主屏幕。
方案B：电脑和手机同一 Wi-Fi，在此文件夹打开 PowerShell 运行 `python -m http.server 8000`，
手机访问 http://电脑IP:8000 。

## 进度同步
「我的」页 → 导出（复制文字）→ 另一设备「导入」。建议每周备份一次。

## 扩充内容
- 在「我的」页添加或批量导入自己的词和句子。
- 或直接编辑 data.js。

## iPhone 发音练习：必读
发音诊所要用麦克风，iPhone 必须通过 **https 网址** 打开（不能直接打开文件）。
1. 把本文件夹发布到 GitHub Pages（免费、无需绑卡）或 Cloudflare Pages / Netlify。
2. 用 **Safari** 打开网址（不要用“添加到主屏幕”的图标练发音，主屏幕模式下语音识别常常不可用）。
3. iPhone 设置 → Siri 与搜索 → 开启“听写”；首次点麦克风时选“允许”。
4. 识别需要联网。
